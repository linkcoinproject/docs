# Embedded Lightning Network

## 6. Embedded Lightning Network

Unlike Bitcoin where Lightning requires external software, Linkcoin embeds Lightning directly in the core:

| Aspect | External LN | Embedded LN |
| :--- | :--- | :--- |
| **Setup complexity** | High | None |
| **Peer network** | Separate | Unified P2P |
| **Key management** | Separate keys | Unified keychain |
| **User experience** | Technical | Mass adoption ready |
