# Glossary

*   **Adaptor Signature**: Signature locked to external secret revelation
*   **Channel Factory**: Multi-party funding for multiple channels
*   **DID**: Decentralized Identifier (W3C standard)
*   **IronTX**: Linkcoin’s non-malleable transaction format
*   **IronTxId**: Stable transaction ID excluding signatures
*   **LinkNet**: Unified protocol layer on Linkcoin
*   **MuSig2**: Multi-signature aggregation scheme
*   **Virtual Channel**: Channel through intermediary without trust
