## 5.4 Data Links

Embed document hash in transaction for immutable timestamp proof.

### 5.4.2 Decentralized Identity

Linkcoin implements a native DID method: `did:link:<address>`

### 5.4.3 Oracle System

Oracles commit to future data revelations, enabling trustless conditional payments.
