# UTXO Links

## 5.1 UTXO Links

UTXO Links create enforceable relationships between transaction outputs.

### 5.1.1 Link Types

*   **Atomic Links**: Multiple UTXOs must be spent in the same transaction.
*   **Sequence Links**: UTXO B unlocks only after UTXO A is spent.
*   **Provenance Links**: Cryptographic chain tracking asset history.
